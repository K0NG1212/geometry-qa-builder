# M0 · 目标与运行配置

把填充目标说清楚，再确定本轮程序配置；目前目标由 Codex 整理保存。

- 状态：程序基础已实现。
- 执行方式：程序 + 研究决策。
- 输入：用户的领域、尺度轴、长度范围、题量和来源路线。
- 输出：goal.json（助手保存）+ config.json（程序快照）。

## 工作原理与边界

先明确要填哪一格，再保存目标与参数。现有代码校验参数，不会自动解释自然语言或规划检索。

程序检查：正整数限制、材料大小、运行目录不可覆盖。

尚未完成：goal.json 尚无自动路由和校验入口；分类配额、跨批目标追踪尚未实现。

## 怎么看输入输出

实际记录：goal.json（目前由助手保存）；config.json。
运行 python tools/inspect_run.py --run 对应目录 --html，展开本地记录。
公开网站上的示例仅用于解释；目标/检索记录当前由助手保存，并非程序自动产物。

## 单独优化

新增限制或修改默认配置；保持旧 run 的快照不变。

入口为 module.py，schema.json 为本模块契约；AI 模块另有 prompt.md。
共用底层文件读写、基础校验和旧版兼容检查在 builder.py；调度在 pipeline.py。
修改字段契约要同时检查下游，新建 run 保留旧版本。

```text
python -m unittest discover -s tests -p test_m0_scope.py -v
```
