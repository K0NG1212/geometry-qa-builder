# M0 · 范围配置

确定本轮处理多少材料、允许多少候选，并冻结运行配置。

- 状态：程序基础已实现。
- 执行方式：程序 + 研究决策。
- 输入：settings.json、材料包。
- 输出：配置/材料/程序快照。

## 工作原理

验证题量和大小限制，然后建立不可覆盖的运行目录。

## 检查与边界

正整数限制、材料大小、运行目录不可覆盖。

研究范围的取舍仍由人决定；分类配额和参数界面尚未实现。

## 单独优化

新增限制或修改默认配置；保持旧 run 的快照不变。

入口为 module.py，schema.json 为本模块契约；AI 模块另有 prompt.md。
共用底层文件读写、基础格式验证和旧版兼容检查仍在 builder.py；调度在 pipeline.py。
改字段契约时要一起调整消费此字段的下游模块并新建 run，不能假定完全无依赖。

```text
python -m unittest discover -s tests -p test_m0_scope.py -v
```
