01 / 两种尺度，分别记录

输入尺度描述模型看到的对象；推理尺度描述解题需要关注的范围。例如，输入完整蛋白质而只分析一个原子接触，两者不能混为一谈。

主图默认按解题推理尺度分为0.1–1、1–10、10–100和100–1000 nm，保留输入尺度切换。尺寸及测量定义见每道题。

03 / 从感知到设计

Perception从结构中识别、测量或比较几何关系。

Physical Inference在明确条件下，联系几何与物理后果；单纯数值比较不自动成为物理推断。

Generation / Design提出满足约束的结构；结构操作、有效性与目标性质达成需要分别评分。

04 / 模型设计题型，程序构建实例

来源整理 → 题型设计 → 输入与答案规则 → 检查通用构建程序 → 批量实例化 → 自动检查与人工抽审。

当前题目从真实结构与性质数据构建。完整题干、输入附件、答案和评分依据齐全，并通过初筛后，才能进入当前题库。程序检查只验证指定量，不证明领域正确性或题目难度；待审核与正式可用之间保持明确区别。

        流程

        层级频率做什么状态
        L0 自动核验每个实例独立检查器重算、四项唯一、答案键一致、无泄漏、来源哈希已运行
        L1 题型审定每个题型一次人工读题型卡片（考点、题干、物理条件、干扰机制、限制）与两个样例，结论为通过或修改；记录绑定生成代码与注册表行的哈希，任一改变即失效工具已建，未运行
        L2 检查器审阅每个题型一次人工读独立检查器代码（可附一次模型代码审阅）；记录绑定检查器代码哈希工具已建，未运行
        L3 分层抽查每批按 题型 × 来源 × 尺度格 分层；新题型或新来源首批全检，稳定后每层 max(2, 10%)；轻量模型答固定四问，被标记的全部转人工，另抽模型判“通过”的题给人工校准工具已建，未运行
        L4 难度测试每批（不属于审核）模型实际作答学生包，得到正确率未建（用户决定暂缓）

        实例状态：生成 → L0（可暂计配额）→ L1 + L2（题型已审定）→ L3 抽查通过 → 正式计入。抽查不合格：改题型模板，整个题型重新生成一批，不逐题手工修补。
