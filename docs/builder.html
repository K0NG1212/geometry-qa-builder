INSPECT A REAL RUN
我怎么查看这一轮的输入和输出？
下方各模块提供示意数据。实际运行时，每步的请求包与接受结果保存在本地 run 目录。
  1. 直接告诉 Codex：“打开这轮 M2 的实际输入和输出。”
  2. 或生成本批记录查看器：python tools/inspect_run.py --run runs/你的批次 --html
  3. 打开生成的 run-view.html，逐模块展开原始记录；未生成的文件会明确标记。
公开网站不自动读取你的本地 run。真实记录包含内部证据和答案，查看器留在本地；这里展示的示例不算新 QA。
