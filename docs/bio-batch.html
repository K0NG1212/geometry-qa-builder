Watson-Crick G-C 碱基对氢键几何

题干、输入、答案与评分 →

M0–M6 输入输出 ↗ · 下载作答材料 ↓

代表性结果：溶菌酶四个真实二硫键中的 Cys6-Cys127（0.203 nm）与 Cys30-Cys115（0.204 nm）都独立核对到与条目自带 SSBOND 记录一致；Crambin 以 46 个残基装下 3 个二硫键，是该参考结构的知名特征。溶菌酶与 Crambin 的 α 螺旋隔四残基 Cα 间距分别约 0.625 nm 与 0.606 nm，两个互不相关蛋白质的数值相差不到 3%，BNI008 直接引用已通过的 BNP009 数值作比较（不重算），推断这支持了"规则 α 螺旋隔四残基间距是跨蛋白共有的几何规律"这一结论，同时说明差异若达几个 Å 会指向其中一段不是规则螺旋。BNP012 测得 G-C 碱基对三条 Watson-Crick 氢键均落在约 2.7–2.9 Å 的经典范围，与 A-T 对仅两条氢键对比，呼应了"GC 含量越高、DNA 越耐热"这一教科书结论。数值复核改用 Decimal 精度独立重算，并与文件自带的 SSBOND／SEQRES 记录交叉核对，全部 10 道通过。可复算的补充计算程序 ↗（与上方共用同一份工具；6LYZ/1CRN/1BNA 原始 PDB 见上文"数据从哪里来"小节）。
