数据来源

两条目均来自 Crystallography Open Database (COD)，由贡献者置于公有领域：

ZIF-8（沸石咪唑酯框架），COD 4118891：a=16.8303 Å（1.68303 nm），体心立方 I-43m（217 号空间群），48 个对称操作。原始文献：Karagiaridi et al., J. Am. Chem. Soc. 134, 18790 (2012)，DOI 10.1021/ja308786r。原始 CIF 记录一对连接体碳/氢原子存在 63:37 的占位无序（C2/H2 主要位点 vs C2A/H2A 次要位点）；本批工作坐标只使用完全有序的原子，或在需要外环连接体碳时只取占位 63% 的主要位点，次要位点已从工作坐标文件中剔除并在此明确披露。

MOF-5（IRMOF-1），COD 1516287：a=25.8247 Å（2.58247 nm），面心立方 Fm-3m（225 号空间群），192 个对称操作，全部原子占位=1，无无序。原始文献：Lock et al., J. Phys. Chem. C 114, 16181 (2010)，DOI 10.1021/jp103212z。

对称展开复用 tools/recompute_materials_batch2.py 中已审核通过（用于材料×0.1–1nm 批次 MNP004/MNP005/MNI004/MNI005）的通用立方 CIF 对称展开函数；展开后的晶胞组成（ZIF-8: Zn12 C72 H72 N48；MOF-5: Zn32 O104 C192 H96）与 COD 官方 API 自带的 cellformula 字段完全一致，独立确认展开正确。

MNI010 · 初筛通过，待人工审核

ZIF-8（体心）与 MOF-5（面心）遵循不同的消光定则，是否说明更大的晶胞会有不同/更严格的选择定则？要求用两个结构各自已算出的结果作为证据说明真正的成因，并说明仅两个实例能建立什么、不能建立什么。

参考答案：不是晶胞尺寸的因素，而是晶格中心化类型（体心 vs 面心）决定了选择定则，与晶胞参数 a 的大小无关；仅这两个实例可以说明"是中心化类型而非尺寸解释了这一对结构的差异"，但不能就此断言尺寸对任何结构的选择定则都毫无影响，也不能断言所有体心或面心的纳米尺度材料都会有完全相同的行为——只检验了两个具体实例。

方法与审核要点

感知题分三族：全局尺度（MNP006/007/010）穷举扫描一个常规晶胞内某子集（Zn 亚晶格或全部原子）的所有原子对，找到最大间距及取得该间距的两行，要求真正的搜索而非读出预给定原子对，将生物/量子域已审核通过的全局尺度方法族推广到周期性材料对象；晶面间距（MNP008/009）复用材料×0.1–1nm 批次已通过的立方晶面公式，这次落在 1–10nm 只是因为晶胞本身大了一个数量级，低阶反射的间距本身超过 1nm。推断题围绕衍射物理：布拉格角（MNI006/007）复用已通过的 MNI001/MNI004 方法族，并要求解释晶胞变大为何导致衍射角变小；结构因子消光（MNI008/009）复用已通过的 MNI002/MNI005 方法族，在真实大晶胞骨架上验证体心与面心两种不同的系统消光选择定则；比较题（MNI010）是本批的综合任务，要求区分"晶胞尺寸"与"晶格中心化类型"两个容易混淆的因素，并明确两个实例能支持什么结论、不能支持什么结论。

ZIF-8 的占位无序（连接体外环碳原子 63:37 两个位置）已在证据记录中明确披露并从工作坐标中剔除次要位点，不是隐藏处理。结构因子振幅使用原子序数 Z 作为近似 X 射线散射权重，与材料×0.1–1nm 批次（MgO/CsCl）已采用的约定一致，不是完整的 Cromer-Mann 原子形状因子。

独立复核（runs/materials-nm-v04-001/independent_checks.py）从零重写了 CIF 对称展开与穷举扫描（不导入本批主计算脚本 tools/recompute_materials_batch2.py），用 Decimal 精度独立重新解析两份原始 CIF；10/10 全部通过，且与主计算路径逐位一致。
