ANSWER DESIGN / SINGLE CHOICE
答案怎么设计：四个选项，唯一正确。
模型只输出 A、B、C 或 D；解释、证据及其余三项为什么错保留在审核侧。数值选项按升序排列（位置即数值秩），正确值的秩在同一题型的批次内轮换，避免“总选最大/最小”；分类选项（反射、候选结构）把正确项放在批次轮换的位置。凑不齐三个有依据的干扰项时记录失败，不随意补数。
能力四个选项是什么验证重点本轮题型
感知四个数值、空间关系或结构图程序计算正确结果；干扰项来自可解释错误且与正确值保持间隔命名键角、主链二面角、最大间距、回转半径
推断四个性质值、区间或物理结论相同条件下正确项有依据，另外三项可排除受力路径导数、衍射消光
设计选择四个候选结构，或四种修改方案明确初始结构、目标和约束，四项都满足约束且只有一项唯一最优构象设计选择
设计选择不等于开放结构生成；论文优化案例路线仍缺实例。完整答案规范 ↗ · 规则 JSON ↗

01 / 定义
题型决定规则
明确科学考点、输入范围、输出格式和验证函数。模板集中审查，避免每个实例重新讨论。
对应 M0–M3
02 / 构造
换结构，算答案
同一模板读取不同结构，生成简短问题和数值答案。解释与文献证据放在审核侧。
对应 M4
03 / 验证
全量计算，分层抽查
校验输入和数值、记录失败；模板变化重点复查，稳定模板按来源和难度抽样。
对应 M5–M6
