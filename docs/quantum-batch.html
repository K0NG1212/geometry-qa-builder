方法与审核要点

感知题（QNP002–006）不再依赖补充计算器：construction 阶段直接使用 schema 注册的 xyz_distance/xyz_angle 验证器，容差分别 ≤0.0001 Å 和 ≤0.05 度，数值由可信 Python 代码从附件坐标计算，M4 提示词明确要求"不得凭空猜答案"，我方提交的构题计划中这些题的 answer_text 均为 null。这比 QNP001 使用的 evidence_review 路由更严格。

QM7-X 不提供官方连接表；哪两个原子"最近"由标准共价半径距离启发式判断，仅用于选择题目中要问的具体两/三个原子（例如"与该硫原子测量距离最短的氧原子"），题干本身只描述测得的距离/角度，不对键级、杂化或官能团身份下结论——这是遵循 M4 提示词"不得仅凭原子间距推断成键或官能团"的直接结果。

4 道推断题（QNI001/002/003/004）延续 QNP001 已通过初筛的方法：QNI001/002 是同一 force_projection.py 公式在新分子上的直接复用；QNI003 在同一分子上比较两个独立位移的力响应，明确要求不对哪个位移更"物理上更可能"下结论；QNI004 是新设计，利用官方 DIP（标量）与 vDIP（三分量）字段计算偶极矩大小及其带符号变化，并要求模型用矢量分量自行核对官方标量场，内建一次一致性检查。全部 9 道题的独立复核见 independent_checks.py：对感知题用 Decimal 精度重新计算距离/角度（角度另用 atan2 公式，区别于构造阶段的 acos 公式）；对推断题用 Decimal 精度重新计算力投影点积与偶极矢量幅值；全部从 8000.hdf5 独立重新解析，不导入本批的主计算脚本，9/9 通过。
