Two reactive chiral dopants built on isosorbide, LRCD (from L-isosorbide) and RRCD (from D-isosorbide), were each mixed into the same reactive nematic host and photopolymerised as planar cholesteric coatings. Take the average refractive index of the host as 1.6. The attached evidence.txt gives the evidence (facts E1–E4 from Dinc et al., Org. Chem. Front. (2024); numbers as reported in the paper). From the two coatings, compute the ratio of the apparent helical twisting powers, |HTP(LRCD)| / HTP(RRCD), and choose the explanation. Choose the option in which both the value and the conclusion are correct.

选项：
A. |HTP(LRCD)| / HTP(RRCD) ≈ 0.90. LRCD twists the host only about three quarters as strongly; as enantiomers the two have the same intrinsic |HTP|, so the deficit reflects the lower enantiomeric excess of LRCD, inherited from L-sorbitol that contains some D-sorbitol.
B. |HTP(LRCD)| / HTP(RRCD) ≈ 0.76. LRCD twists the host only about three quarters as strongly; as enantiomers the two have the same intrinsic |HTP|, so the deficit reflects the lower enantiomeric excess of LRCD, inherited from L-sorbitol that contains some D-sorbitol.
C. |HTP(LRCD)| / HTP(RRCD) ≈ 0.90. LRCD and RRCD are not true mirror images but diastereomers, so their intrinsic twisting powers differ; enantiomeric purity plays no role.
D. |HTP(LRCD)| / HTP(RRCD) ≈ 0.76. LRCD and RRCD are not true mirror images but diastereomers, so their intrinsic twisting powers differ; enantiomeric purity plays no role.
